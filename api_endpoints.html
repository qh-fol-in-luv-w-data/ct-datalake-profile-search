CT DataLake API Endpoints

Danh sách các câu lệnh cURL cho toàn bộ 11 endpoints. Bấm nút Copy để sao chép nhanh.

1. ct_datalake.api.root (GET)

Kiểm tra trạng thái chung của API.

curl -X GET "https://devapp.ctpai.vn/api/method/ct_datalake.api.root" \
  -H "Authorization: token 539cc7c60b48834:451f510c38b665d"

2. ct_datalake.api.health (GET)

Kiểm tra trạng thái health check chi tiết.

curl -X GET "https://devapp.ctpai.vn/api/method/ct_datalake.api.health" \
  -H "Authorization: token 539cc7c60b48834:451f510c38b665d"

3. ct_datalake.api.semantic_search (POST)

Tìm kiếm ứng viên bằng cơ chế BM25 + FAISS.

curl -X POST "https://devapp.ctpai.vn/api/method/ct_datalake.api.semantic_search" \
  -H "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Kỹ sư AI có kinh nghiệm LLM",
    "mode": "in",
    "top_k": 5,
    "use_cache": "1"
  }'

4. ct_datalake.api.semantic_search_llm (POST)

Tìm kiếm BM25, sau đó đưa kết quả vào LLM phân tích thêm. 

curl -X POST "https://devapp.ctpai.vn/api/method/ct_datalake.api.semantic_search_llm" \
  -H "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Kỹ sư AI có kinh nghiệm LLM",
    "mode": "in",
    "top_k": 5,
    "use_cache": "1"
  }'

5. ct_datalake.api.jd_match (POST)

So khớp giữa một đoạn text (JD) với hồ sơ ứng viên.

curl -X POST "https://devapp.ctpai.vn/api/method/ct_datalake.api.jd_match" \
  -H "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  -H "Content-Type: application/json" \
  -d '{
    "jd_text": "Tìm kiếm ứng viên có 3 năm kinh nghiệm Python...",
    "mode": "in",
    "top_k": 5,
    "fast": false
  }'

6. ct_datalake.api.jd_match_upload (POST)

Upload file JD dạng văn bản để AI tìm kiếm ứng viên tương ứng.

curl -X POST "https://devapp.ctpai.vn/api/method/ct_datalake.api.jd_match_upload" \
  -H "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  -F "file=@/path/to/your/jd.pdf" \
  -F "mode=in" \
  -F "top_k=5" \
  -F "fast=false"

7. ct_datalake.api.jd_analyze (POST)

Đọc JD (file PDF) bằng Vision AI, tự động tách từ khóa, search trực tiếp vào Local Redis rồi dùng GPT rerank lại kết quả.

curl -X POST "https://devapp.ctpai.vn/api/method/ct_datalake.api.jd_analyze" \
  -H "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  -F "file=@/path/to/your/jd_file.pdf" \
  -F "source=in" \
  -F "top_k=5" \
  -F "use_cache=1"

8. ct_datalake.api.g600_analyze (POST)

Dành riêng cho các tờ trình G600 (file PDF). Trích xuất lĩnh vực và search.

curl -X POST "https://devapp.ctpai.vn/api/method/ct_datalake.api.g600_analyze" \
  -H "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  -F "file=@/path/to/your/g600_document.pdf" \
  -F "source=in" \
  -F "top_k=5" \
  -F "use_cache=1"

9. ct_datalake.api.jd_parse_only (POST)

Bóc tách các trường thông tin từ Text JD qua GPT.

curl -X POST "https://devapp.ctpai.vn/api/method/ct_datalake.api.jd_parse_only" \
  -H "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Yêu cầu kỹ sư phần mềm biết Python, SQL, và 3 năm kinh nghiệm..."
  }'

10. ct_datalake.api.draft_document (POST)

Tự động dùng AI để soạn thảo các loại văn bản (thư mời, đề nghị tư vấn...)

curl -X POST "https://devapp.ctpai.vn/api/method/ct_datalake.api.draft_document" \
  -H "Authorization: token 539cc7c60b48834:451f510c38b665d" \
  -H "Content-Type: application/json" \
  -d '{
    "candidate_info": "{\"name\": \"Nguyen Van A\", \"expertise\": \"AI/ML\"}",
    "doc_type": "invite_collab",
    "org_name": "CT Group",
    "sender_name": "Nguyen Van B",
    "extra_note": "Gửi trước ngày 15/10"
  }'

11. ct_datalake.api.get_context (GET)

Dùng cho Frontend lấy thông tin Session & CSRF Token.

curl -X GET "https://devapp.ctpai.vn/api/method/ct_datalake.api.get_context" \
  -H "Authorization: token 539cc7c60b48834:451f510c38b665d"
